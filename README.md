# Data source. 


## GSE19830

The biological experiment uses the publicly available **GSE19830** dataset from the NCBI Gene Expression Omnibus (GEO). The dataset was originally introduced by Shen-Orr et al. in *Nature Methods* (2010) for tissue deconvolution experiments. It contains gene-expression measurements from multiple rat tissues, including both pure-tissue samples and experimentally prepared mixtures with known proportions. The samples were measured using Affymetrix microarrays and processed using RMA normalization.

**Data source:** NCBI GEO, accession **GSE19830**  
**Reference:** Shen-Orr et al., “Cell type-specific gene expression differences in complex tissues,” *Nature Methods*, 7(4):287–289, 2010. DOI: 10.1038/nmeth.1439.


## AVIRIS Cuprite

The AVIRIS Cuprite dataset was acquired by the Airborne Visible/Infrared
Imaging Spectrometer (AVIRIS) over the Cuprite mining district in Nevada, USA.
We use the 1997 Cuprite reflectance product (`f970619t01p02r02`) in our
experiments.

- **Official download:** [NASA/JPL AVIRIS Cuprite](https://aviris.jpl.nasa.gov/data/free_data.html) (https://aviris.jpl.nasa.gov/data/free_data.html)
- **Data product:** `f970619t01p02r02`
- **Number of pixels used:** 47,500
- **Number of endmembers:** 14
